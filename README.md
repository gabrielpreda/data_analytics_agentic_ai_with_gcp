# Objectives

- 📊 Analyze and process large-scale data with BigQuery
- 🤖 Build intelligent agents with Gemini and the Google Agent Development Kit (ADK)
- 🛠️ Connect agents to tools, APIs, MCP servers, BigQuery, and external systems
- 🧩 Design multi-agent systems
- 📚 Build Retrieval-Augmented Generation (RAG) systems using Vertex AI RAG Engine
- ☁️ Deploy agents to Google Cloud
- 📈 Create interactive analytics dashboards with BigQuery and Looker Studio
